Research note

Model: implied value = TVL x sizeMultiple(TVL) x 0.75 x growthMult x maturityMult. sizeMultiple is fitted at run time from the snapshot's own live tokens: log10(multiple) = 3.02 - 0.48 x log10(TVL), n = 128, corr -0.41, clamped to [0.02, 0.80].

Backtest: 5-fold cross-validation on the 128 live tokens gives median |log10 error| 0.56 (3.6x), against 0.72 (5.3x) for a flat median multiple. A category multiple adds nothing once size is in, so the model has no category term.

Pre-token haircut: 0.75. Exclusions: 144 pre-token protocols are off the board because they are wrapped, bridged, staked or exchange products of tokens that already trade, not protocols awaiting a token launch.

Limits: the snapshot is frozen 2026-11-14. Multiples are comparables, not predictions, and no protocol name is hardcoded into the model.

Check it yourself: open any protocol and the detail view recomputes its implied value from TVL, growth and age with the same functions above — the stored and recomputed values agree for every row on the board. The model panel below fits the size curve and runs the backtest live in this page from the 128 live tokens, so the numbers in this note are the page's own output, not typed-in claims.
